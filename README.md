# Full Stack Developer Capstone Project

This repository contains my Full Stack Developer Capstone Project.

## Project Overview

The project is a car dealership application that allows users to explore car dealerships, view dealership information, register and log in, and submit customer reviews.

## Technologies Used

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Django, Python
- **Database:** IBM Cloudant
- **Version Control:** Git and GitHub
- **Deployment and CI/CD:** GitHub Actions and IBM Cloud

## Main Features

- User registration, login, and logout
- Browse car dealerships and filter dealers by state
- View dealership details and customer reviews
- Submit reviews and analyze customer sentiment
- Manage dealership data through the backend APIs
